# Keystone

Personal AutoHotkey v2 setup: one script that loads hotkey modules, global and per-app.

## Setup

1. Install [AutoHotkey v2](https://www.autohotkey.com/).
2. Run `Keystone.ahk`. The control panel opens.
3. Tick **Start with Windows** in the panel (or run `Install.ahk`, which toggles it).

Close any other AutoHotkey script that uses CapsLock first; two scripts hooking the same key conflict.

## Control panel

Opens when you run `Keystone.ahk` by hand or double-click the tray icon. It shows whether hotkeys are active, lists every hotkey, and has Pause / Resume, Reload, Open folder and Start with Windows. `Esc` hides it.

Starting with Windows and reloading pass `--quiet`, so the panel stays closed. Modules describe their hotkeys with `Cheatsheet.Add(section, keys, action)`.

## Layout

| Path | Purpose |
|---|---|
| `Keystone.ahk` | Entry point. Includes the library, config and module indexes. |
| `config/apps.ahk` | App catalog: launch target and window title per app. |
| `lib/` | Shared code: `App` (Run, IsActive, Toggle), `Text` (selection and paste), `Web` (open or search), `Sound`, `DarkMenus`, `StartMenu`, `Startup`, `Cheatsheet`, `Keystone` (pause, reload, tray). |
| `ui/` | The control panel. |
| `modules/global/` | Hotkeys active everywhere. Register each file in `_index.ahk`. |
| `modules/apps/` | Hotkeys active only in one app, wrapped in `#HotIf Apps.<Name>.IsActive()`. |

## Hotkeys

CapsLock is a modifier and no longer toggles caps.

| Keys | Action |
|---|---|
| `CapsLock` + `n` `a` `e` `i` `o` `u` | ñ á é í ó ú (add `Shift` for uppercase) |
| `CapsLock` + `/` | ¿ |
| `CapsLock` + `t` `w` `f` `s` | Toggle Terminal, browser (Zen), Explorer, Spotify |
| `CapsLock` + `d` `c` `m` `g` | Toggle Discord, Docker Desktop, Obsidian, Steam |
| `CapsLock` + `↑` `↓` `←` `→` | Selected text to UPPERCASE, lowercase, Sentence case, Title Case |
| `Alt` + `G` | Open the selected text if it is a URL, otherwise search it on DuckDuckGo |
| `CapsLock` + mouse wheel | Volume up / down |
| `CapsLock` + middle click | Mute / unmute |
| `Win` + `PrintScreen` | Snipping Tool capture (instead of saving a full screenshot) |
| `Win` + `Space` | Disabled, so it no longer switches input language |
| `CapsLock` + `F5` | Reload Keystone (plays a ding) |
| `CapsLock` + `F12` | Pause / resume all hotkeys (plays a sound, tray tip shows "paused") |

Sounds come from `C:\Windows\Media`, so the repo ships no audio files. Tray and context menus follow the Windows dark/light theme.

`Toggle` hides the app if it is focused, focuses it if it is open, and launches it otherwise.

| Keys | Action |
|---|---|

| `Alt` + right click | Escape |

## Tray icon

An arch with a gold keystone; it turns grey while hotkeys are paused. The icons in `assets/` are generated by `python tools/make_icon.py` (standard library only), which also writes `assets/keystone-preview.png`.

## Tests

```
"C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe" /ErrorStdOut tests\text.test.ahk
"C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe" /ErrorStdOut tests\web.test.ahk
```

Each prints `all passed` (exit code 0) or each failure (exit code 1).

## Adding a module

1. Create `modules/global/<name>.ahk` or `modules/apps/<name>.ahk`.
2. Add `#Include <name>.ahk` to that folder's `_index.ahk`.
3. Describe its hotkeys with `Cheatsheet.Add(...)` so they show in the panel.
   Hotkeys that combine `Win` with the mouse must call `KeepStartMenuClosed()`, or releasing `Win` opens the Start menu.
4. New apps go in `config/apps.ahk`.
